Rules

Dislike Button

Hover ON

  • Cursor changes from arrow to pointer
  • Dialogue box fades in over the course of 0.5 seconds underneath the thumbs down icon reading "I Dislike This"
    • When "Click ON" is active, Dialogue box is changed to read "Undo Dislike"
  • Backdrop behind the thumbs down icon goes from dark gray to light gray over the course of 0.5 seconds

Hover OFF

  • Cursor changes from pointer to arrow
  • Dialogue box fades out over the course of 0.3 seconds
  • Backdrop returns from light gray to dark gray over the course of 0.3 seconds

Click ON

  • Thumbs down icon switches from outline to filled with white over the course of 0.3 seconds
  • Thumbs down icon briefly increases in size by 20% then returns to original size over the course of 0.5 seconds
  • Background flashes from light gray to a lighter gray over the course of 0.1 seconds
  • Monochrome confetti effect over the course of 0.5 seconds
  • New button state is entered that changes dialogue box content
  • Like button enters a deemphasized state; the thumbs up icon and backdrop darken over the course of 0.3 seconds
  • If the video is currently liked, the Like button is simultaneously returned to its default state and the like counter decreases by 1
  • Video is marked as disliked within the database

Click OFF

  • Thumbs down icon reverts back to outlined state over the course of 0.3 seconds
  • Background flashes from light gray to a lighter gray over the course of 0.1 seconds
  • Thumbs down icon briefly increases in size by 10% then returns to original size over the course of 0.5 seconds
  • New button state is reverted and dialogue box behavior reverts to default
  • Like button exits the deemphasized state; the thumbs up icon and backdrop return to their default appearance over the course of 0.3 seconds
  • Video is removed from dislike section in database

Like Button

Hover ON

  • Cursor changes from arrow to pointer
  • Dialogue box fades in over the course of 0.5 seconds underneath the thumbs up icon reading "I Like This"
    • When "Click ON" is active, Dialogue box is changed to read "Unlike"
  • Backdrop behind the thumbs up icon goes from dark gray to light gray over the course of 0.5 seconds

Hover OFF

  • Cursor changes from pointer to arrow
  • Dialogue box fades out over the course of 0.3 seconds
  • Backdrop returns from light gray to dark gray over the course of 0.3 seconds

Click ON

  • Thumbs up icon switches from outline to filled with white over the course of 0.3 seconds
  • Thumbs up icon briefly increases in size by 20% then returns back to original size over the course of 0.5 seconds
  • Background flashes from light gray to a lighter gray over the course of 0.1 seconds
  • Number of likes next to thumbs up icon is updated in real time by +1
  • Confetti effect over the course of 0.5 seconds
  • New button state is entered that changes dialogue box content
  • Dislike button enters a deemphasized state; the thumbs down icon and backdrop darken over the course of 0.3 seconds
  • If the video is currently disliked, the Dislike button is simultaneously returned to its default state
  • Video is marked as liked within the database

Click OFF

  • Thumbs up icon reverts back to outlined state over the course of 0.3 seconds
  • Thumbs up icon briefly increases in size by 10% then reverts back to original size over the course of 0.5 seconds
  • Background flashes from light gray to a lighter gray over the course of 0.1 seconds
  • Number of likes next to thumbs up icon is updated in real time by -1
  • New button state is reverted and dialogue box behavior reverts to default
  • Dislike button exits the deemphasized state; the thumbs down icon and backdrop return to their default appearance over the course of 0.3 seconds
  • Video is removed from like section in database

More Options Button

Hover ON

  • Cursor changes from arrow to pointer
  • Dialogue box fades in over the course of 0.5 seconds underneath the three dots icon reading "More Options"
  • Backdrop behind the three dots icon goes from dark gray to light gray over the course of 0.5 seconds

Hover OFF

  • Cursor changes from pointer to arrow
  • Dialogue box fades out over the course of 0.3 seconds
  • Backdrop returns from light gray to dark gray over the course of 0.3 seconds

Click ON

  • Three hollow dots icon switches from outline to filled with white over the course of 0.3 seconds
  • Three dots icon briefly increases in size by 20% then returns to original size over the course of 0.5 seconds
  • Background flashes from light gray to a lighter gray over the course of 0.1 seconds
  • Dropdown menu with options "Download" and "Report" appears beneath the three dots icon
  • Dialogue box moves above the three dots icon while the dropdown menu is open
  • New button state is entered that changes how dropdown menu behaves

Click OFF

  • Three dots icon reverts back to outlined state over the course of 0.3 seconds
  • Three dots icon briefly increases in size by 10% then returns to original size over the course of 0.5 seconds
  • Background flashes from light gray to a lighter gray over the course of 0.1 seconds
  • Dropdown menu with options "Download" and "Report" disappears
  • Dialogue box returns beneath the three dots icon
  • New button state is left and dropdown menu behavior is reverted

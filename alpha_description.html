IDM 241: Alpha Description

Youtube

Object: Dislike Button

Location

The dislike button can be found almost directly in the center of the page horizontally, on the right side of the bottom of the video player. It is to the right of the like button, and to the left of the share button. By default, it has a bubble behind it and the outline of a thumbs down shape.

SOMETHING OF NOTE: THE LIKE COUNTER DOES NOT GO DOWN, AS DISLIKES ARE NOT PUBLIC.

Triggers

  • Hover ON
  • Hover OFF
  • Click ON
  • Click OFF

Rules

Hover ON

  • Cursor changes from arrow to pointer
  • Dialogue box pops up underneath the thumbs down icon reading "I Dislike This"
  • Backdrop behind the thumbs down icon goes from dark gray to light gray

Hover OFF

  • Cursor changes from pointer to arrow
  • Dialogue box dissapears
  • Backdrop returns from light gray to dark gray

Click ON

  • Thumbs down icon switches from outline to filled with white
  • Background flashes from light gray to a lighter gray
  • Video is marked as disliked within the database

Click OFF

  • Video is removed from dislike section in database
  • Background flashes from light gray to a lighter gray
  • Thumbs down icon reverts back to outlined state

Loops and Modes

Loops

N/A

Modes

  • Thumb icon changes from outline to filled state
  • While hovering over the dislike button, "I dislike this" dialogue box shows up, no matter state of dislike
  • Dislike icon is the toggle between two states: Neutral (default) and disliked
  • Clicking the dislike icon when neutral changes the video to a disliked state in the database
  • Clicking the dislike icon while disliked changes the video to a neutral state in the database
  • The dislike interaction can be repeated infinitely
